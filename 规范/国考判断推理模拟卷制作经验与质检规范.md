# 国考判断推理模拟卷制作经验与质检规范

> 版本：V1.0 ｜ 形成日期：2026-10-24  
> 复盘对象：国考判断推理原创模拟卷（一），35题、含答案解析。  
> 用途：记录实际经验、检查范围及复用边界，配合固定模板执行。

配套入口：[国考判断推理35题出卷固定模板](./国考判断推理35题出卷固定模板.md)。原有[基础命题规范](./公考判断推理真题命题与解析规范.md)保留不动；本文补充生产实施经验，不将样本中的编辑问题固化为规范。

## 1. 本次实际完成了什么

- 采用本次核对的2025年国考样本结构：图形10题、定义10题、类比5题、逻辑10题。
- 第31—35题共用一组排列条件，各子题附加条件独立。
- 题目与解析分区，含答案速查表；最终Word共19页。
- 10张完整题图、3张空间题解析辅助图，共13张内嵌图片。
- 题干、答案、考点及解析共用一份源数据，答案表由源数据生成。
- 程序计算或断言检查涉及第1—10题、第30—35题；其余内容进行了定义、关系或论证层面的自查。
- 使用Word导出的预览核对编号、文本内容及逐页版式；发现问题后修改并重新检查。
- 没有另行组织独立教师盲审或学员试测，不能据此声称真实作答时间、难度和区分度已经验证。

重要边界：程序检查不等于独立解题。部分检查使用了预先声明的对称轴数量、图论顶点度数或选项分组；它们能检查一致性，但仍需核对这些声明与实际图像是否吻合。

## 2. 哪些经验应固定，哪些只是本卷参数

### 2.1 后续必须固定的方法

1. 先核对目标样本，再定题量结构；不能仅凭印象分配四大模块。
2. 先构造完整解法，再写题干和干扰项。
3. 题干、图片、答案、解析使用稳定的对应关系，并由同一源数据生成成品。
4. 可枚举问题保留解集；空间问题保留坐标、面关系或高度构造。
5. 数学正确性和图像可读性分开验收，二者缺一不可。
6. 成品必须实际渲染；源码正确、XML中有编号，均不能替代实际显示检查。
7. 修改选项或图形后，重新校验答案和解析；修改排版后，重新核对分页。
8. 把自查、程序验证、独立审题与试测区分记录，不夸大完成程度。

### 2.2 不应固化的偶然结果

- 19页不是标准页数；13张图不是标准插图数。
- 本卷A、C、D各9题，B为8题，是本卷结果，不是下套卷的配额。
- 公共材料有10个可行方案，是本题的性质，不是五题组合材料的统一要求。
- 35分钟是建议训练时长，不是对所有考生、所有卷型的实测结论。
- 具体定义名称、纪录片排期题材、各题答案及考点顺序都不属于固定模板。
- 某个程序默认难度字段，不等于逐题进行了难度评估。

## 3. 命题与解析层面的有效做法

### 3.1 图形题：从可计算对象出发

本次用确定的方格集合、顶点坐标、面标签、占位矩阵等生成图形。优点是题图可重建，规律可检查，改动可追踪。

后续规则：

- 平移旋转分别记录主体、位置、方向和步数，避免只检查一个运动主体。
- 黑白运算直接在对应方格上计算，不凭整体外观判定“求异”。
- 对称题核查精确几何关系，不把肉眼近似对称当作严格对称。
- 面积计数先确保格子等大；笔画计数先明确连通关系及相交处是否相连。
- 对外框区域、黑点等计数对象有歧义时，应在题面表达或图形设计阶段消除，不能只在解析中规定计数口径。
- 精确几何图优先用参数化绘图；不能把生成式图片的视觉逼真当作几何证明。

### 3.2 空间题：排除之后还要验证可实现

六面体题不能只排除相对面相邻。剩余选项仍可能因公共顶点周围的面序相反而成为镜像，不可通过真实旋转得到。若数字只作面标签，应在题干说明不考查数字自身朝向；若考查图案朝向，就必须连同面内方向一起校验。

截面题先确定平面，再求其与立体各条棱的交点。本次用三点确定平面并算出六个棱中点，不能把三点直接连成三角形就当作截面。宣称“正六边形”时，除边数外，还核对等边、等角等性质。

三视图题先统一前后左右约定，再把投影视为高度约束。正确项应给出具体堆叠方案，错误项应指出无法满足的某个方向。题干中的“是否悬空”“阴影格含义”“右视图方向”都可能影响答案，应事先写清。

### 3.3 定义题：逐要件对应，而非只看词面

将定义拆成主体、目的、方法、时点、过程、结果及排除条件，再核对每个案例。多定义题先找两个概念真正的差别；选非题须复核设问方向。

正确项与定义相符之外，还要检查其他项是否也能在通常理解下符合。不能仅因为正确项包含更多题干关键词就认定唯一。真实概念的简化表述应保持本义，专业真实性有疑问时应查证。

### 3.4 类比题：二级辨析必须有题干依据

“工具—对象—功能”等一级关系可能覆盖多个选项，应继续比较观察与加工、种属与组成、先后顺序、语义感情色彩等。二级属性必须同时适用于题干和正确项，不能为排除其他项临时补造标准。

词项使用统一关系符号“∶”；比较的是语义关系，不是词面长度、字数或是否具有同一个字。

### 3.5 论证题：力度与必要性分开检查

- 加强、削弱题先定位论点与论据，分清替代原因、对照证据、机制证据与话题相关但不触及推论的信息。
- 对照研究类正确项可以很强，但不应因为文字特别长、控制条件明显比其他项完备而泄露答案。
- 必要前提用否定代入复核。满足前提未必足以使结论成立，不把必要条件解释成充分条件。
- 本次周转箱题通过明确制造处置排放、实际使用次数及额外回收清洗排放，消除了比较口径歧义。换素材后仍须检查单位、基准、平均值和计算范围。
- 解释题要解释题干真正统计的现象；不能用“总体损害下降”替代“某种害虫造成的损害比例下降”。

## 4. 本次发现的问题与固定处理办法

| 发现的现象 | 定位与处理 | 固定验收要求 |
| --- | --- | --- |
| 首轮Word题号变成字母、选项继续编号 | 调整编号定义及实例顺序、唯一标识和编号范围，重新渲染后恢复正常 | 读实际渲染结果，核对题号1—35及每题A—D |
| 默认样式带入蓝色装饰线或斜体 | 新建卷中显式设置字体、颜色、斜体及段落边框 | 检查样式继承后的实际效果，不只看设置代码 |
| 相切圆在缩放后看起来分离 | 使用精确整数坐标并保证共用切点，复核笔画拓扑 | 放大检查源图，缩小到打印尺寸再次检查 |
| 截面题的点标签靠近其他标记 | 调整标签偏移，不改变几何点的位置 | 标签、点、虚线和边界不能互相遮挡 |
| 截面虽正确，解析视角却把六边形压成窄带 | 解析图换用更适合展示截面的视角，并注明旋转视角 | 图的投影须可读；旋转后点位对应与空间关系仍须一致 |
| 某个正确选项明显长于其他项 | 缩减不必要文字，保留关键证据 | 比较四项信息量，不让字数成为答题捷径 |
| 末页仅剩一道短解析 | 局部调整末段间距和行距，20页调整为19页 | 不删推理、不缩小到难读；页数不是优先目标 |
| 页面数减少后可能遗留旧预览图 | 本次工作目录仍有旧轮次页图，验收按最终PDF实际页数核对 | 每轮独立渲染目录或明确清点，不能把旧页当成最终页 |

编号问题的多项修正是一起完成并通过验证的；不能据此断言今后所有串号问题都由其中某一个原因造成。

## 5. Word自动编号与版式实施约定

### 5.1 编号结构

本次采用真正的Word自动编号，而不是把数字当普通正文逐项硬写。继续复用时：

1. 题目区使用一个连续十进制编号实例；解析区另用一个，从1重新开始。
2. 每道文字选项题使用独立的A—D编号实例；公共条件另用“（1）”样式，不与题号共用。
3. 编号ID从文档已有定义之后分配，避免冲突；本次新建的抽象编号设置不同的`nsid`。
4. 编号XML中的抽象定义放在编号实例之前，层级子元素按所用实现的正确顺序写入；不要随意拼接XML。
5. 新增列表、复制段落或调整选项后，重新渲染检查编号是否被合并、续接或重启。

当前实现可参考[build.py](../.work/guokao35/build.py)中的`Numbers`类，但复用后仍须做真实Word显示检查。

### 5.2 分页与图片

- 单题的题干、设问、图和选项尽量作为一个整体，不让标题或选项孤悬。
- “与下段同页”只在块内部使用，最后一段结束关联，防止把大量题目连成一个无法分页的整体。
- 某个单题确实超过一页时，应合理设计续页，不能强行连排导致溢出。
- 图片等比缩放，按最终纸面尺寸核对线宽、黑点和标签。高像素不自动等于好读。
- 解析图与题图分开保存、分开引用；学生题图不能带红色答案线。
- 版式清理仅针对本卷需要改变的样式，不能把既有教师文件的样式一概清除。

## 6. 四层质检：检查什么、不能证明什么

### 第一层：题目语义与干扰项

逐题检查设问方向、必要信息、四项依据及最强干扰项。定义、类比和论证题尤其不能只用字母一致性检查替代内容审题。

“全部解析结尾都写了同一个答案”只说明文稿绑定一致，不证明答案正确。

### 第二层：数学模型与可行性

- 方格运算：从输入集合或矩阵计算结果，并与四项比较。
- 立体重构：检查相对面和可通过真实旋转实现的面序；有方向图案时增加方向校验。
- 截面：求交点、共面性、边数；若断言等边等角，补充对应计算。
- 三视图：搜索高度配置，确认正确项可构造、其他项不可构造。
- 量词推理：构造满足前提的模型，对每个选项检查必然性，并为错误项寻找反例。
- 排列组合：枚举公共可行解及各子题解集，按设问量词检查选项。

预防要求：

- 先断言公共解集、各条件解集非空，再检查“所有解都满足”。
- 尽量从实际题目数据计算结论，不把预设答案或预写计数当成新的独立证据。
- 对称轴数、图论度数等若仍由人预先输入，要单独核对输入与图像；程序通过不能省略这一步。
- 选项唯一性指对本题所声明规则及自然理解的唯一性；有限序列可能有牵强替代规律，需继续做合理性审题。

### 第三层：源数据与文件绑定

检查题数、连续题号、答案范围、选项数量、题图存在性、解析结尾及媒体嵌入。答案速查表和逐题解析从同一记录生成。

本卷第1—7题的选项在图片中，第8—35题共28组文字选项，因此文字层出现28组A—D是正确的。新卷应按每题的选项呈现方式计算，不能永远硬编码28组或13张图。

### 第四层：实际渲染与逐页视觉检查

1. 生成Word后，用可用的文档渲染方式导出预览；本次因常规渲染依赖不可用，使用本机Word后台导出PDF，再渲染页面图片。
2. Word后台处理应新建自己的实例、只读打开源文件、禁用宏及弹窗；结束时只关闭本任务创建的文档和实例，不终止用户其他Word进程。
3. 从渲染PDF抽取文本，检查真正显示的题号、A—D、答案标题、题干和解析是否完整。
4. 逐页查看图片；文本抽取无法发现线条断开、标签遮挡、图形失真或答案标记误入题图。
5. 任何内容或排版修订后重新渲染。若复用上一轮视觉验收，须证明未变页图像一致，且新旧页数、页序和受影响页面均已核对。
6. 以最终渲染版本交付，不以中间的`passed`记录代替最终验收。

本次终版文本校验确认35个题号、35个答案标题、28组文字选项及全部源稿正文存在；这是显示完整性的证据，不等于全部题目已经独立自动求解。

| 文件 | 用途 | 新卷复用时必须处理 |

| [content.py](../.work/guokao35/content.py) | 题目、答案、解析的单一数据源 | 替换题目，重新核对难度、题号和公共材料 |

| [verify.py](../.work/guokao35/verify.py) | 本卷几何、有限模型及绑定检查 | 重写与新题相应的模型、断言及预期值 |
| [render_word.ps1](../.work/guokao35/render_word.ps1) | 本机Word后台导出预览 | 核对源文件、预览输出路径及运行环境 |
| [verify_render.py](../.work/guokao35/verify_render.py) | 渲染文本编号及正文完整性检查 | 按新卷更新题数、选项模式和标题识别规则 |
| [build_info.json](../.work/guokao35/build_info.json) | 本卷构建元信息 | 新卷生成新记录，不直接复制作为验证结果 |
| [verification.json](../.work/guokao35/verification.json) | 本卷程序校验结果 | 与当前源稿版本对应，修改后重跑 |
| [render_verification.json](../.work/guokao35/render_verification.json) | 本卷终版渲染文本校验结果 | 与最终成品对应，修改后重跑 |

复用顺序：为新卷建独立目录 → 复制需要的实现或提取通用部分 → 先修改全部输入输出路径 → 更新题目和图形 → 更新验证模型 → 构建 → 验证 → 渲染 → 逐页检查。

不要直接运行旧`build.py`来制作新卷：其输出仍指向模拟卷（一），可能覆盖已有成品。原有Word若被教师人工修改，也不能在未核对变更前重新生成覆盖。

Python、Word、字体和渲染工具的位置属于运行环境信息；换电脑或环境升级后应重新探测，不把本机缓存版本路径写成永久依赖。

## 8. 对基础规范的实施补充

- “答案均衡”属于软性观察指标，不是正确性的条件。长连选可以复核，但不因此自动判错。
- “独立盲审”是面向正式教学发布的重要审题环节。尚未完成时如实记录，不把自己重读或程序检查称为盲审。
- 默认交付一份题目在前、解析在后的Word。只有实际需要时才派生纯学生版或逐题教师版，不自动增加多份内容近似的文件。
- 所有可调整值写入任务单，不把本次的分页、图数、解集大小或准确率推测升级为硬标准。
- 本模板不替代目标年份考试结构核查。新增样本或教师新要求与默认方案不一致时，以核对后的任务要求为准。

维护原则：经验必须有具体案例或验证依据；规则应能执行、能检查、能说明适用边界。只保存“下次更仔细”一类感想，不足以形成稳定模板。
