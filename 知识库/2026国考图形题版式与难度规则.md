# 2026国考图形题版式与难度规则

> 形成日期：2026-10-25。依据本地[2026年国考行政执法类题本](../真题/真题录制（事业单位、独立省份、国省考）/国考/2026年国家公务员录用考试【行政执法卷】.docx)及其[解析稿](../真题/真题录制（事业单位、独立省份、国省考）/国考/2026年国家公务员录用考试【行政执法卷解析】.docx)的第76—85题。题本首页标注“**网友回忆版**”；以下是本地资料所呈现的训练参考结构，尚未核实为官方原卷或官方难度标准。使用前与本次目标类别、年份再次对照。

## 1. 用户反馈与上一卷的问题

用户指出[原创模拟卷（一）](../模式题/国考判断推理原创模拟卷（一）-35题（含答案解析）.docx)的图形题整体缺少外框、内容偏简单。逐张查看其[第1—10题题图](../.work/guokao35/assets/)和[渲染PDF首页](../.work/guokao35/preview.pdf#page=1)后可见：图形、问号和选项直接排列在白底画布上；第1、2、4、10题的小网格虽有自身边线，题干序列与选项仍无共同外框；第3、8、9题的图形单元也没有统一方形图位。[旧绘图程序](../.work/guokao35/figures.py)没有按题型绘制图位外框。页面PNG已按用户要求清理，链接改指向保留的PDF。

旧卷第3题直接把对称轴数从1、2、3、4延续到5，第4题只核对黑格数恒定；第8题分轴对称与中心对称，第9题分一笔画与两笔画。它们作为入门练习可以成立，但不符合本次要求的2026卷仿真难度。旧卷的[程序校验](../.work/guokao35/verify.py)核对答案、几何与图片是否嵌入，[逐页记录](../.work/guokao35/visual_review.json)核对可读性和有无裁切；两者均未设置“外框是否符合题型”和“与目标卷复杂度是否接近”的验收项。新卷须增设这两项检查，且不能把自评难度等同于教师盲审或学员试测。

## 2. 本地2026行政执法卷的图形结构

第76—85题共10题，按题目形式为 **4道规律题＋3道空间题＋3道六图分类题**。新卷独立编号时可对应第1—4、5—7、8—10题。此处借鉴题型配额、视觉语法和所测能力，不复用来源的具体图案、条件、数字、选项或答案。

| 原题号 | 形式和外框 | 能力目标，可换成原创机制 |
| --- | --- | --- |
| 76 | 题干五幅图加问号处在同一个六格横向外框；四个候选图在四格横向外框内 | 对由多个局部组成的图形，同时识别连接关系与局部数量，不只数整图某一种元素。 |
| 77 | 同样是六格题干外框与四格选项外框；每格内还有统一的方格坐标 | 分别追踪内、外区域中的运动主体或顶点，确定各自的位置变化。 |
| 78 | 题干分为两组三格外框，第二组含问号；选项为四格外框 | 在两组之间迁移规则，并用属性与笔画／拓扑等第二条件排除近似选项。 |
| 79 | 完整3×3九宫格外框，问号占一格；选项为四格外框 | 结合复杂轮廓处理黑白叠加或其他可逐格验算的运算。 |
| 80 | 原立体与四个截面候选排在带分隔线的单一长方框中 | 不规则多面体的三点定面、截面求交与方向核对。 |
| 81 | 双立方体题图及四幅外表面展开图置于白底，**没有共用长方外框** | 对两个带图案的立体分别验证相对面、公共边次序和面内方向。 |
| 82 | 前后视立体图与四个拼合候选置于白底，**没有共用长方外框** | 空间拆分／拼合，结合体块数量、颜色与前后遮挡，注意“除哪项外”的选非方向。 |
| 83—85 | 六图按3×2排列，**每幅图各有等大的独立方形外框**，圈号在框外；四个分组选项用文字列出 | 从复杂图案里提取同形、相交、相对位置等细节；分类标准须覆盖三幅且排除另外三幅。 |

因此，“有外框”要落实为**与该题型相符的图位结构**。规律题的六格／九宫格必须形成连续外边框，分类题的六个独立小框必须大小、线宽和编号位置一致；第81、82题保持立体图所需的白底空间，不机械添加与样本不符的装饰框。

### 2026-10-25 用户追加的两组对照题横排规则

用户明确要求“两条式的要在一条横线上，不要分两行”。今后制作两组对照式图形题时，第一组3格和第二组3格置于**同一水平基线**，两组之间留清楚的组间空白；第二组问号保持在同一排。候选项可以另起一排。不得把第一组放上排、第二组放下排，也不得让 Word 自动换行把两组拆开。以整体题图嵌入并在最终印刷尺寸检查线条、标记和组间界限；九宫格及六图分类继续按各自版式排布。本条是用户对今后成品的明确要求，优先于参考题本的上下组示例。

## 3. 新卷绘图与难度门槛

1. **先定规则后绘图**：每题先写标准解法、唯一正确项和三类错误路径，再生成每幅图及选项。逐图保存可复算的数据，例如节点与连线、占格、黑白区域、顶点坐标、立体面朝向；不要只保存一张难以复核的合成图。
2. **统一视觉尺寸**：题干格与选项格保持一致的尺寸、边线粗细和内边距；问号在指定格内居中，选项 A—D 与各格一一对齐。分类题六幅图的外框及圈号统一，黑白打印后仍能区分细线、交点和填色。题图中不出现辅助线、答案痕迹或与解析图混用的标记。
3. **复杂度来自辨析**：保留少量识别入口明确的题目，但不再用连续单调计数、裸几何图形或一个显眼属性覆盖多题。至少让中高难题需要观察两个主体、两组迁移、局部与整体、面内方向或空间可实现性中的多步关系；干扰项与正确项应只差一个关键条件，并能逐项说明错因。不得为了“变难”增加无解歧义、模糊像素或无功能信息。
4. **题型各有验证方式**：规律题检查所有题干图及唯一选项；九宫格逐行／逐列复算；空间题用坐标、折叠或构造模型证明正确项可实现且其余不可实现；分类题分别验证两组三幅图共享的规则，并排查另一种同样成立的分法。选非题额外复核设问方向。
5. **难度标签要有依据**：逐题记录预估难度及造成难度的具体步骤、近似干扰项和阅读负担。作为本工程新卷的设计目标，10道图形题可控制在基础约1—2道、中档约5—6道、较难约2—3道；这是命题目标，不是2026年官方统计。独立审题与试测未完成时，只能标记“命题估计”，不能声称达到实测难度。
6. **排查绕过考点的捷径**：不能只验证预设规则成立，还要检查正确项是否被更显眼的低层级属性单独暴露。例如考查面之间共边关系时，不能让正确项成为唯一三角形轮廓；考查折后面邻接时，不能让“折后相邻”组恰好全在平面展开图中直接共边。通过同轮廓干扰、相同点线面总数、不同平面距离等控制，保留真正需要比较的关系。本次55题专项第8、26、28题据此修改。
7. **凹角术语准确**：直角折线围成的多边形，在向内凹入的拐点处内角为270°；解析称“内凹拐点”或“270°内角”，不把这个多边形内角误称90°直角。
6. **排查绕过考点的捷径**：不能只验证预设规则成立，还要检查正确项是否被更显眼的低层级属性单独暴露。例如考查面之间共边关系时，不能让正确项成为唯一三角形轮廓；考查折后面邻接时，不能让“折后相邻”组恰好全在平面展开图中直接共边。通过同轮廓干扰、相同点线面总数、不同平面距离等控制，保留真正需要比较的关系。本次55题专项第8、26、28题据此修改。
7. **凹角术语准确**：直角折线围成的多边形，在向内凹入的拐点处内角为270°；解析称“内凹拐点”或“270°内角”，不把这个多边形内角误称90°直角。

## 4. 生成后的逐图质检

- **原图检查**：逐题核对题干图、选项图、答案和解析所说的属性、数量、位置与空间关系；确认四个选项确实只有一个满足全部条件。
- **版式检查**：将10张最终题图与本规则第2节逐项对照，核对连续外框／分组外框／独立小框／白底例外、格数、圈号、线宽、闭合、图案可辨性及选项顺序。新增“图位结构通过／未通过”记录，不用“图片存在”代替。
- **成品检查**：生成 Word 及其套卷 Markdown 索引后，导出最终 PDF；以实际印刷尺寸逐页查看图形，特别检查是否裁边、缩小后线条粘连、灰度丢失、题目跨页分离、解析辅助标注进入题图。任何修订后重新导出与复核。
- **审题记录**：程序校验、人工视觉检查、未参与命题者的独立解题和学员试测分别记录。没有完成的环节标为未进行；争议题退回修改，不能仅修改答案字母。
