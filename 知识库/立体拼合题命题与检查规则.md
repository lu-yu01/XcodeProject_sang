# 立体拼合题命题与检查规则

## 0 用户确认的题型优先要求

用户于2026-10-25指出，上一版把多种拼合变式混在一起，不符合其要求。工程中未另行指定时，立体拼合专项应统一为：题干给出一个完整目标和两个已知部件，从四个选项中选择第三部件，三件共同拼合目标。不能擅自混入“两件选结果”“相同部件选非”等题型。下文跨考试变式仅作历史研究。

本次重制的10题，用户明确选择全部采用三黑块版：目标有3个固定黑色小立方体，部件①、②各含1个黑块，每个候选第三部件也各含1个黑块。必须同时保持体块形状与逐格黑白位置。目标正反视图和两个已给部件在题干同一横排；A—D四项在同一横排。

- 白块表面用白色，不以普通透视阴影制造额外灰块；黑色是随部件旋转的材料标记，不能把它当作光照效果。
- 用户于2026-10-25确认题图内删除标题、块数、正背面说明，只保留①②及A—D。必要数量信息列在图片外的Word正文；解析图中的分层、部件归属标记另行保留。去文字只修改文字层，核对实体轮廓和黑格像素不变。
- 用户随后明确四个候选共用一个横向大外框，内部三条竖线分成等宽四格；A、B、C、D分别居中放在各格下方、外框之外，不放在图形上方。调整框线与字母位置时保持立体及黑格不变。
- 题型验收先于几何验收：逐题检查“一个目标、两个已知部分、四选一第三部分”，再检查目标3黑、两个已给各1黑及四候选各1黑。程序证明拼合正确不能代替题型符合需求。
- 颜色求解要求每个黑格落在目标黑格，每个白格落在目标白格；不能只验形状或只验黑块数量。每题至少设置一个忽略颜色可拼、保持颜色却不可拼的近似选项。
- 解析涉及上下层时按同一坐标朝向说明；目标展示只绕竖轴旋转，避免为了显黑块而交换高度轴，导致解析层次与题图冲突。
- 各考试的年份与黑白形式以具体原图为准，不能仅凭某一年份断言全部考试同式。已核对的严格同式及相似但不同式样例见[本次形制研究](../.work/assembly_black10_20261025/source_findings.json)。

## 2 出题与干扰项

- 先确定凹凸补全、两部件组合、相同部件组合、三部件补形或选非等具体形式，再建完整三维模型。立体拼合题不能全部退化成一层平面拼图。
- 部件为刚性整体，允许空间旋转和平移；不允许拆分、变形、镜像、相互重叠。题干明确是否必须完整使用所有部件及是否允许空隙。
- 单位立方体模型以整数三维占格保存。核对每个部件面连通、体积及目标占格；图中呈现的摆放姿态不限制其拼合时的朝向。
- 中高难题优先使用同体积、相近外接尺寸及局部轮廓的干扰项。体积一致只是必要条件，还须验证局部凸块、缺口、层间位置及所有部件同时放入的可行性。
- 镜像部件可能不能通过真实旋转得到；必须验证具体形体的手性，不能把所有镜像一概视为错误。
- 题目答案只需选项唯一；实际拼合方案允许因整体旋转、相同部件交换等存在多个等价构造。不得把方案不唯一误判为题目多解。
- 同一专项内排查部件与候选的旋转等价重复，避免后题直接复用前题的答案形状。

## 3 图形表达

- 每个物体用能互相补充的视角表达；注明两幅图是同一物体，不能让考生误认为需要两件相同部件。灰度若只用于面的朝向，须说明不表示材料颜色约束。
- 同一题的单位立方体使用相同投影尺度；部件、目标、选项标题、外框及A—D对应清楚，线条在实际打印尺寸可辨。
- 核对遮挡实格和遮挡空格。若双视图仍有隐含块，统一注明各物体总块数，或增加可辨的视图、分层信息；不能仅对正确项补注数量形成提示。
- 总块数只有在可见结构和可隐藏位置共同确定形体时才足以消除歧义。仍可同数量换位而保持视图不变时，必须补图或重画。
- 四选项块数相同的题，数量标注用于识图，不承担选出答案的作用。
- 解析另绘分层拼合图，所有层保持相同朝向，自底向上标号，以部件名标示各格。目标之外的空格与漏填空隙分清。
- 分层图底部说明与最末行网格之间保留明确间距；增加网格行数后重新核对底部留白，不让图注贴住或覆盖格子。

## 4 正确性与成品检查

- 单位格模型枚举立方体的24种正向旋转及目标内可行平移，逐项验证不重叠、无遗漏地覆盖目标。镜像不混入旋转集合。
- 正选题保留正确项的实际构造，并证明其余项不可拼；选非题核对唯一不可拼项，同时验证其余三项均可拼。选非题的解析示意展示可拼项时注明对应字母。
- 用另一实现复核40个选项的可拼性，并核对源部件与构造中的部件确为正向旋转同构；不能只检查答案字母一致。
- 数学模型通过后，逐图核对模型和可见线面，实际导出Word预览并逐页检查。源图、答案或版式有修改时重新生成和检查。
- 每份成品仍配套知识库内同名Markdown索引及检查记录。难度属于命题估计，未做教师盲审或学员试测时如实标注。
- 临时页面PNG完成检查后按[预览清理规则](./工程协作与套卷验收规则.md)清理；保留必要题图、解析图、少量参考图、PDF及历史检查记录。
