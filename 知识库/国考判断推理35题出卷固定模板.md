# 国考判断推理35题出卷固定模板

> 版本：V1.1 ｜ 建立日期：2026-10-24 ｜ 资料复核：2026-10-25
> 用途：复用命题流程、组卷结构、解析方式和交付标准，持续生成新的原创判断推理模拟卷。  
> 固定的是生产方法和质量要求，不是题干、答案、具体考点排列或成品页数。

## 1. 使用入口与依据

每次出卷先阅读[工程协作与套卷验收规则](./工程协作与套卷验收规则.md)并填写第2节的任务单，再按第3—9节执行。第10节提供可以直接复制的出卷指令。遇到影响命题、格式或验收的疑问，先向用户提问并记录答复。

- 基础命题风格：[公考判断推理真题命题与解析规范](./公考判断推理真题命题与解析规范.md)。
- 制作经验与技术验收：[国考判断推理模拟卷制作经验与质检规范](./国考判断推理模拟卷制作经验与质检规范.md)。
- 全量资料入口：[真题资料总索引](./真题资料总索引.md)与[判断推理真题归纳与命题依据](./判断推理真题归纳与命题依据.md)。
- 已完成的参考成品：[国考判断推理原创模拟卷（一）](../模式题/国考判断推理原创模拟卷（一）-35题（含答案解析）.docx)。

本模板依据用户提供的国考样本及模拟卷（一）的实际制作过程形成。其中“10＋10＋5＋10、最后5题共用材料”参照本地2025年国考三类卷判断部分及本卷命题设定。目录内2015—2024年国考表格样本的判断部分为10＋10＋10＋10，共40题；事业单位A/B/C类另有综合判断推理。故本模板的35题结构**仅作该系列的默认训练方案**，不宣称适用于所有年份、地区和考试类别。

执行优先级：教师本次明确要求 → 已核对的目标年份与考试类别 → 本模板的默认方案。若本次任务明确延续35题原创模拟卷系列，可用默认方案；若只是笼统要求“出国考卷”且目标年份、类别会影响题量，先向用户提问。结构发生变化时，先更新任务单和命题蓝图，再生成题目；不得只改封面而沿用旧题量。

| 11—20 | 定义判断 | 10 | 单定义、多定义、选非相结合 |

| 26—30 | 逻辑判断 | 5 | 论证评价与演绎推理 |

### 3.2 起稿用35题考点蓝图

以下是从模拟卷（一）抽象出的可用起点。新卷可以替换同模块考点和调整顺序，不应连续多套照搬相同解题结构、相同素材和相同干扰项组合。

| 题号 | 默认主考点或任务 | 主要区分点 |
| --- | --- | --- |
| 1 | 位置规律 | 分别追踪两个运动主体 |
| 2 | 样式运算 | 求同、求异、求并等操作辨别 |
| 3 | 属性规律 | 对称性及对称轴数量 |
| 4 | 数量规律 | 明确计数对象或面积单位 |
| 5 | 立体重构 | 相对面、相邻面顺序、镜像排除 |
| 6 | 截面判断 | 找出完整交点，而非只连已知点 |
| 7 | 三视图或空间构造 | 方向约定、占位与高度一致性 |
| 8 | 六图分类：属性 | 区分相近的对称属性 |
| 9 | 六图分类：笔画 | 连通关系、端点与交点 |
| 10 | 六图分类：数量关系 | 两种数量之间的稳定对应 |
| 11 | 单定义：行为过程 | 目的、方法与结果同时匹配 |
| 12 | 单定义：目标与手段 | 相似行为背后的目的不同 |
| 13 | 单定义：结构条件 | 完整单元、独立性或排除条款 |
| 14 | 单定义：新旧关系 | 利用旧条件与直接重复旧任务的区别 |
| 15 | 多定义：相近概念 | 找出真正的区分标准 |
| 16 | 单定义：因果链 | 原因、认知、行为与结果的顺序 |
| 17 | 单定义：跨主体条件 | 共同使用与局部差异兼容 |
| 18 | 单定义：反馈过程 | 初始行为与后续强化相衔接 |
| 19 | 选非定义 | 正确识别不符合项及其关键缺口 |
| 20 | 多定义：时点或类型 | 同一行为在不同阶段的归属 |
| 21 | 语义关系 | 近义、反义、褒贬与排列顺序 |
| 22 | 对应关系 | 一级关系相似时作二级辨析 |
| 23 | 集合关系 | 种属、组成、交叉等不能混用 |
| 24 | 流程关系 | 先后顺序及环节属性 |
| 25 | 填空类比 | 两侧关系类型、方向和层级一致 |
| 26 | 削弱论证 | 论据到结论之间的关键漏洞 |
| 27 | 加强论证 | 排除干扰因素或补充机制证据 |
| 28 | 必要前提 | 否定代入；必要不等于充分 |
| 29 | 解释现象 | 同时解释矛盾两端 |
| 30 | 演绎结论 | 量词、包含关系或条件方向 |
| 31 | 公共材料：可能成立 | 寻找至少一个可行解 |
| 32 | 公共材料：附加条件 | 条件锁定后的必然结论 |
| 33 | 公共材料：必然成立 | 在全部剩余解中成立 |
| 34 | 公共材料：可能取值 | 对目标变量取值去重计数 |
| 35 | 公共材料：充分限定 | 判断哪一附加条件产生唯一解 |

## 4. 单题命题卡：先完成逻辑，再写题面

每题保留以下内部记录。命题卡、考点和校验数据不进入学生题目区。

```text
题号：【1—35】
模块：【填写】
主考点：【一个清楚的能力目标】
次考点：【无／用于进一步区分的条件】
预计难度与依据：【填写】
素材性质：【命题设定／真实来源／常识性素材】
来源或原创说明：【填写】
识别入口：【考生从题面哪一处想到该方法】
标准解题链：【先独立写出，不能只写答案字母】

题干：【填写】
设问：【填写，核对正向／选非、可能／必然、最能／必要】
A.【填写】
B.【填写】
C.【填写】
D.【填写】
正确答案：【A／B／C／D之一】

A项成立依据或错误机制：【填写】
B项成立依据或错误机制：【填写】
C项成立依据或错误机制：【填写】
D项成立依据或错误机制：【填写】
最强干扰项及排除依据：【填写】
唯一性／最优性核查：【填写证据，不写空泛的“已检查”】
是否依赖未给出的常识或假设：【否／是，如何补足】
题图：【无／文件名与图形源数据】
解析图：【无／文件名与标注目的】
解析：【识别入口—推理过程—选项落点】
程序检查：【适用范围、结果与未覆盖内容】
教师独立审题：【未进行／结果】
修订记录：【问题、修改、复核结果】
```

通用约束：

1. 正确项先由解题链得到，再确定放在A—D哪个位置，不从答案分布倒推题目。
2. 错误项分别对应可解释的误区；至少有一个具有真实迷惑性的干扰项。
3. 四项的长度、句式、专业程度尽量接近，正确项不能总是最长、限定最齐全。
4. 题干给足必要信息。不能在解析中第一次补出决定答案的条件。
5. “最能支持／削弱”须说明相对力度；不能机械把所有非正确项都称为完全无关。
6. 新卷不能只替换人名、数字、图形颜色而保留上一卷的整套题目。应检查素材、关系链及错误机制的重复。

## 5. 公共材料五题专项模板

```text
根据以下材料，回答第31—35题。
【场景：交代对象数量、任务、可选位置或类别】
【基本规则：每个对象使用几次、是否允许并列、是否允许空位】
（1）【条件一】
（2）【条件二】
（3）【条件三】
（4）【条件四；条件数量可调整】
各题所增加的条件仅对本题有效。

31.【可能成立的排列／匹配／分组】
32.如果【局部条件一】，以下哪项一定为真？
33.如果【局部条件二】，以下哪项一定为真？
34.如果【局部条件三】，【目标变量】的可能取值共有几种？
35.增加以下哪项条件，可以唯一确定【完整安排】？
```

内部验证方法：

- 枚举满足公共条件的可行解集合S，先确认S不为空。
- 每个子题从原始S出发，叠加本题条件得到Sᵢ；不继承其他子题的附加条件。
- “可能”：至少一个解满足该选项；“一定”：每个解均满足该选项；“不可能”：没有解满足该选项。
- “取值种数”：统计目标变量不同取值，不误数成完整方案数。
- “唯一确定”：该附加条件下完整方案数恰为1；不能只锁定某个对象的位置。
- 条件题须先确认Sᵢ非空，避免把空集合上的程序判定误当成实际必然结论。
- 一个公共材料可以有多个可行安排，但每道单选题只能有一个符合设问的选项。
- 必然题的错误项尽量提供反例；可能题的正确项提供可行构造。

## 6. 统一解析与成品模板

### 6.1 逐题解析格式

```text
【题号】.答案：【X】
考点：【题型：主考点】
解析：【识别入口；说明为什么采用该方法】
【完整推理：规律／定义要件／关系链／论点与论据】
【各选项依据；相似选项须比较关键差别】
【需要时插入独立解析图】
故正确答案为【X】。
```

- 图形：元素特征 → 规律 → 问号处或分类结果 → 干扰项。
- 定义：关键要件 → 各选项逐项匹配 → 概念边界。
- 类比：一级关系 → 必要的二级属性 → 对应顺序 → 排除。
- 论证：论点、论据及缺口 → 选项的作用 → 强度或必要性比较。
- 演绎：翻译或列条件 → 推导／构造／反例 → 回答设问。
- 选非题结尾加“本题为选非题”；不使用“显然”“看着像”代替推理。

## 8. 固定生产流程与交付门槛

按顺序完成，每一阶段保留能复查的产物：

1. **锁定任务**：核对样本及任务单，确认35题配额、编号和公共材料范围。
2. **建立蓝图**：逐题指定考点、预估难度、题材和干扰机制，排除重复。
3. **先解后题**：完成命题卡、标准解法和选项依据，再整理成正式题面。
4. **单一数据源**：题干、题图、答案表和解析共用同一份题目记录，防止改一处漏一处。
5. **绘图与验证**：精确几何使用可计算的图形源；可枚举问题保留解集或验证结果。
6. **内容审查**：检查定义边界、类比层级、论证强度和所有选项；明确哪些只是自查、哪些已独立审题。
7. **同步建档并渲染**：生成Word时在“知识库/套卷索引”建立同名Markdown索引与待检记录；实际打开或导出逐页预览，不能把“文件成功保存”视为完成。
8. **生成后复核**：对最终Word、Markdown、PDF和逐页图重新做内容、答案、编号、图片及版本一致性检查；人工逐页查看图形、字体和排版，修订后重新验证受影响内容和分页。
9. **交付留档**：Word成品进入“模式题”，Markdown索引与复核结论进入“知识库/套卷索引”；源稿、绘图、程序报告和预览进入该卷独立工作目录。建议与修改意见同步记录到知识库。

发布前勾选：

- [ ] 35题完整，模块配额和公共材料范围正确。
- [ ] 每题四个选项，唯一正确或唯一最优项有充分依据。
- [ ] 题干不缺条件，解析没有新增决定性前提。
- [ ] 学生题面无答案、考点或提示性辅助线泄露。
- [ ] 图形源数据、实际题图和解析三者一致。
- [ ] 公共材料及每个附加条件都实际可满足。
- [ ] 换序后的选项、答案、解析、题图标号同步更新。
- [ ] Word显示的题号为1—35，选项逐题A—D，解析编号为1—35。
