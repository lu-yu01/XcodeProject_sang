# 公考判断推理真题命题与解析规范

> 版本：V1.0  
> 形成日期：2026-10-24  
> 适用范围：判断推理真题整编、仿真命题、套卷编排、答案与解析撰写、讲义制作  
> 样本依据：`国京考套卷刷题（题干+答案）-正常题号.docx`、`17-18.2025-2023山东.docx`

## 1. 对当前出题方法的总体判断

当前材料体现出的核心方法，不是先写知识点再随意配题，而是先锁定真实公考的题型外壳和能力目标，再用稳定的解题路径组织题干、选项和解析。

整体风格可以概括为：

1. **真题口吻优先**：保留不同地区、不同年份的原始设问习惯，不强行把所有题目改成同一种文风。
2. **模块化组卷**：围绕图形推理、定义判断、类比推理、逻辑判断四大模块成组编排，题型切换有明显边界。
3. **考点先行**：每题都能归入一个主考点；较难题可叠加一个次考点，但不无边界复合。
4. **干扰项来自真实误区**：错误选项通常不是随机错误，而是对应漏条件、关系顺序颠倒、概念混淆、可能与必然混淆、因果倒置等典型误判。
5. **解析强调识别路径**：先说明“为什么想到这个考点”，再展示规则或要件，最后落到选项，而不是只公布答案。
6. **图形题重视可视化复盘**：平移、旋转、折叠、截面、三视图等难以纯文字说明的题目，会增加编号、轨迹、颜色或辅助线标注。
7. **材料兼顾生活感与专业感**：题目常从科技、医学、生态、公共管理、心理、文化、教育和日常生活取材，但解题所需信息尽量在题干内部闭合。

后续命题、整理和解析均以本规范为默认标准。样本中的缺题、错标、格式混用等属于编辑问题，不视为风格特征。

## 2. 成品模式

根据使用场景，固定采用以下两种模式之一。一份成品内不得无提示混用。

### 2.1 模式 A：套卷刷题版

适合计时训练、阶段测验、模考和纸质刷题。

结构如下：

```text
判断推理套题
（20XX年地区）

题目区：题干、题图、A—D选项
……

判断推理套题答案与解析（20XX年地区）

题号.答案：X
解析：……
故正确答案为X。
```

执行要求：

- 题目区不泄露答案、考点标签和提示性标注。
- 答案解析集中置于整套题之后，并与题目顺序完全一致。
- 地区、年份、套题编号、起止题号必须在题目区和解析区双向核对。
- 适合国考、北京等按整套训练组织的材料。

### 2.2 模式 B：逐题精讲版

适合课堂讲义、课后复盘、自学资料和教研校对。

结构如下：

```text
20XX年地区

题号.题干
A.……
B.……
C.……
D.……

题号.【答案】X
【解析】……
故正确答案为X。
```

执行要求：

- 一题一闭环，解析紧跟该题。
- 图形题可以在解析中另附标注图，但题目原图必须保持干净。
- 同一年度要么全部逐题跟解，要么全部后置解析。
- 适合山东卷等需要边做边讲、边练边复盘的材料。

### 2.3 交付文件建议

同一套题需要多场景使用时，优先生成两份：

- `刷题版`：只有题目，答案解析统一后置；
- `教师版`：逐题给出答案、考点、推理过程和干扰项说明。

不得在刷题版题图中保留红线、蓝线、编号或正确选项痕迹。

## 3. 套卷结构与题量编排

### 3.1 四大模块

| 模块 | 主要能力 | 常见子题型 | 典型位置 |
| --- | --- | --- | --- |
| 图形推理 | 规律识别、空间想象、操作推演 | 位置、样式、属性、数量、重构、截面、拼合、三视图、分类 | 套卷前段 |
| 定义判断 | 抽取要件、匹配案例、辨析边界 | 单定义、多定义、列举型、脉络型、辨析型 | 中前段或后段 |
| 类比推理 | 识别词项关系并精细比对 | 语义、集合、映射、语法、常识关系 | 中段 |
| 逻辑判断 | 演绎推理与论证评价 | 加强、削弱、前提、解释、结论、翻译推理、真假、排列组合 | 后段 |

地区卷可以调整模块顺序和题量，但同一年度内部应保持模块连续，不随意穿插。

### 3.2 难度节奏

一套题的难度应形成梯度：

- **基础题**：单一考点，识别入口明显，步骤短；
- **中档题**：入口不直接，需二次观察或两个要件联合判断；
- **较难题**：考点复合、条件较多、需要排除比较或图示推演；
- **压轴题**：可使用复合题、排列组合、复杂空间重构，但信息必须充分。

不宜连续堆叠同一种难题。图形题内部应在平面规律、空间重构、生活化空间观察之间形成变化；逻辑判断内部应在论证题和形式推理题之间形成变化。

### 3.3 答案分布

- A、B、C、D总体均衡，避免肉眼可见的固定循环。
- 原则上避免同一答案连续出现四次及以上。
- 不得为了“配平答案”修改已经严密成立的题目；应通过替换选项顺序实现。
- 调整选项顺序后，必须同步更新答案、解析和图中标注。

## 4. 通用命题流程

每道题按以下顺序生产：

1. **确定能力目标**：明确题型、主考点、次考点和预期难度。
2. **先写标准解法**：在写题干前，先写出唯一、完整、可复核的解题链。
3. **构造正确项**：正确项必须完整满足规则或题干结论，不能依赖模糊常识。
4. **构造干扰项**：每个干扰项对应一种可说明的典型错误路径。
5. **回写题干**：补足所有必要条件，删除无功能信息，控制阅读负担。
6. **唯一性校验**：证明正确项唯一，并逐项说明其他选项错在哪里。
7. **解析撰写**：按照本规范第 10 节的结构写出可教学的解析。
8. **版式落地**：根据刷题版或精讲版排版，绑定题号、题图、选项和解析。
9. **盲测复核**：由未参与命题者独立作答；出现多解、争议或需脑补条件时退回修改。

### 4.1 单题命题卡

每道原创或改编题建议保留以下教研信息：

```text
题型：
主考点：
次考点：
难度：基础 / 中档 / 较难 / 压轴
标准解法：
正确答案：
A项错误机制：
B项错误机制：
C项错误机制：
D项错误机制：
是否依赖外部常识：否 / 是（说明）
是否需要解析标注图：否 / 是
```

## 5. 题干与选项的通用风格

### 5.1 题干

- 使用正式、克制、信息密度高的公考书面语。
- 先给材料或定义，再给设问；设问放在题干末尾。
- 条件较多时使用“（1）（2）（3）”分项，避免塞进一个超长句。
- 专业概念必须在题干中给出足够定义，不把冷知识当作解题门槛。
- 科学研究类材料要区分相关与因果、样本与总体、倾向与必然。
- 人名优先使用“小王、小李、甲乙丙”等中性称谓，避免无关人物设定。

### 5.2 设问

正向设问与选非题都可使用，但必须显著标明：

- 正向：`属于的是`、`可以推出`、`最能支持`、`最合理的解释`；
- 反向：`不属于的是`、`不能推出`、`最不能支持`、`除哪项外`。

解析结尾必须再次提醒选非题，例如：`本题为选非题，故正确答案为C。`

### 5.3 选项

- 统一四个选项，按 A、B、C、D 排列。
- 同一题四个选项的句法结构、信息量和具体程度尽量对齐。
- 正确项不能仅因更长、更专业或更完整而明显突出。
- 干扰项必须“有依据地错”，不能荒谬到无需理解题干即可排除。
- 涉及关系顺序时，选项应有顺序颠倒型干扰项。
- 涉及强度时，选项应有“有时—往往—必然”“可能—一定”的强弱干扰。
- 涉及定义要件时，错误项各自违反不同核心要件。
- 不使用“以上都对”“以上都不对”。

## 6. 图形推理命题规范

### 6.1 考点体系

图形推理以如下观察路径为主：

1. **元素组成相同**：优先考虑位置变化，如平移、旋转、翻转、路径、方向和步数。
2. **元素组成相似**：优先考虑样式运算，如叠加、求同、求异、黑白运算和自定义运算。
3. **元素组成不同**：优先考虑属性或数量，如对称性、曲直性、封闭性、点线面、部分数、笔画数。
4. **出现立体或展开图**：进入空间重构，如六面体、截面、拼合、三视图、投影、视角和运动过程。

该路径既是解析的“入口说明”，也是命题时控制可识别性的依据。

### 6.2 常用题面

- 一组顺推；
- 两组类比；
- 九宫格；
- 六图分类；
- 空间展开与折叠；
- 截面、拼合、三视图；
- 操作规则复合题；
- 与真实空间观察结合的投影、影子、倒车视角、运动顺序题。

### 6.3 命题要求

- 每题必须有一个主规律；需要次规律时，只用于进一步区分剩余选项。
- 平移、旋转必须写清移动主体、方向、步数和区域。
- 数量规律必须明确“数什么”，不能在点、线、面之间随意切换。
- 对称题要区分轴对称、中心对称、对称轴数量及方向。
- 样式运算要能够写成稳定规则，并在至少一组图形中验证。
- 六面体与展开图必须检查相对面、公共边、相邻顺序和图案方向。
- 截面题必须实际验证切面经过的棱、面或顶点，不凭视觉猜测。
- 复合操作题先给统一“操作字典”，子题只调用已定义操作。
- 题图中的线宽、黑白、灰度、编号、间距保持一致；无意的视觉差异不能成为线索。

### 6.4 干扰项设计

优先采用以下错误机制：

- 方向正确但步数错误；
- 步数正确但顺逆时针错误；
- 只处理外框，遗漏内部元素；
- 只满足数量规律，不满足属性规律；
- 把求同误作求异；
- 镜像与旋转混淆；
- 展开图中相对面误判为相邻面；
- 截面形状正确但顶点或边数错误；
- 三视图中遮挡关系或高度判断错误。

### 6.5 图形题解析模板

```text
题号.【答案】X
【解析】元素组成相同/相似/不同，优先考虑……

观察发现：……（说明移动主体、数量对象或属性特征）。
将规律应用到问号处：……
只有X项符合。

故正确答案为X。
```

空间题或复杂动态题增加一张解析标注图。标注图可使用红色强调当前步骤、蓝色虚线表示参照或轨迹；颜色必须有固定含义，不得仅作装饰。

## 7. 定义判断命题规范

### 7.1 选材方式

定义可来自管理、法律、经济、医学、心理、生态、教育、传播、人工智能等领域。选择陌生但可自足判断的概念，避免仅凭生活印象作答。

定义结构优先覆盖以下要件：

- 主体；
- 客体；
- 时间或场景；
- 目的；
- 方式或手段；
- 原因；
- 结果；
- 必要条件或阈值；
- 排除性条件。

### 7.2 题型

- 单定义：判断是否符合一个概念；
- 多定义：区分两个或多个相近概念；
- 列举型：定义中列出若干并列情形；
- 脉络型：抓住行为或过程的核心链条；
- 辨析型：概念边界接近，需要精确比较。

### 7.3 选项设计

正确项应完整满足全部核心要件。三个干扰项分别设置不同缺口，例如：

- 主体正确、目的错误；
- 行为相似、发生场景错误；
- 结果符合、原因不符合；
- 满足一般生活理解，但不满足题干的专业定义；
- 符合相邻概念，不符合所问题概念；
- 缺少题干规定的数额、比例、授权或时间条件。

不得让三个错误项都因同一个要件被排除，否则区分度不足。

### 7.4 定义判断解析模板

```text
题号.【答案】X
【解析】第一步：找出定义关键词。

主体：……
方式：……
目的/结果/条件：……

第二步：逐一分析选项。
A项：……，符合/不符合……，排除/保留；
B项：……
C项：……
D项：……

故正确答案为X。
```

较短定义可改用“本题属于单定义，主要考查……要件”的写法，但同一套解析风格必须统一。

## 8. 类比推理命题规范

### 8.1 关系识别顺序

先判断一级关系，再用二级关系精确匹配：

1. **语义关系**：近义、反义、比喻、象征；
2. **集合关系**：全同、种属、组成、交叉、并列中的矛盾或反对；
3. **映射关系**：功能、属性、场所、材料—成品、工具—作用、方式—目的、主体—对象；
4. **语法关系**：主谓、动宾、偏正、并列；
5. **顺序与属性**：先后、必要环节、人工或自然、褒贬、主动或被动。

### 8.2 命题要求

- 题干词项以两项或三项为主，使用中文全角间隔号 `∶`。
- 一级关系不能过于宽泛，至少要有一个二级属性帮助锁定唯一答案。
- 三项式题目要保证前后关系方向一致。
- 专有名词可以使用，但不得要求考生掌握极冷门事实才能作答。
- 若四个选项都具有相似一级关系，必须通过顺序、词性、种属层级、功能对象等二级特征区分。

### 8.3 干扰项设计

- 关系类型相同但顺序相反；
- 一级关系相同、二级关系不同；
- 日常关联强但逻辑关系不精确；
- 词性或语法结构不同；
- 种属关系误作组成关系；
- 矛盾关系误作反对关系；
- 材料与成品的方向颠倒。

### 8.4 类比推理解析模板

```text
题号.【答案】X
【解析】第一步：判断题干词语间逻辑关系。
……与……是……关系；进一步看，……

第二步：判断选项词语间逻辑关系。
A项：……，排除；
B项：……，排除；
C项：……，当选；
D项：……，排除。

故正确答案为X。
```

## 9. 逻辑判断命题规范

逻辑判断分为两条主要命题线：形式推理与论证评价。

### 9.1 形式推理

常见题型包括：

- 条件命题与翻译推理；
- 直言命题、量词与真假关系；
- 一真一假、真假推断；
- 排列、分组、匹配和日程安排；
- 集合包含、传递关系；
- 复合题与多问共用条件。

命题要求：

- 条件必须彼此兼容，且足以推出唯一答案。
- “如果……那么……”“只有……才……”“除非……否则……”的逻辑方向必须准确。
- 数量条件、名次条件和相邻条件不得含歧义。
- 排列组合题应预先列出全部可行解，验证选项结论。
- 复合题的公共条件保持不变，子题只改变设问或增加局部条件。

解析顺序：翻译条件或列表 → 推导关键结论 → 验证选项 → 得出答案。

### 9.2 论证评价

常见设问包括：

- 最能支持；
- 最能削弱或反驳；
- 必要前提；
- 最合理解释；
- 可以推出；
- 不能质疑；
- 论证错误相同。

题干材料宜采用“现象/研究结果—观点或结论”的结构。科技、健康、生态、教育、公共政策等题材较适合，但必须避免把争议性事实当作默认常识。

### 9.3 论证题干扰项

主要使用：

- 与论点话题不一致；
- 只解释论据，不触及论点；
- 重复题干信息；
- 因果倒置；
- 另有他因但力度不足；
- 个例反驳总体趋势；
- 可能性偷换为必然性；
- 扩大或缩小适用范围；
- 支持方向正确但不如另一项直接、明确；
- 看似相关，实际缺少论据到论点之间的桥梁。

### 9.4 论证题解析模板

```text
题号.【答案】X
【解析】第一步：找出论点和论据。
论点：……
论据：……

第二步：逐一分析选项。
A项：……，加强/削弱/无关；
B项：……
C项：……
D项：……

对比……两项，X项对论点的作用更直接/更确定/更全面，力度更强。
故正确答案为X。
```

必要前提题必须使用否定代入或搭桥思路复核；“最能”类题目必须比较力度，不能停留在“两个选项都能加强/削弱”。

## 10. 解析的统一写法

### 10.1 四层结构

所有解析尽量具备四层：

1. **定位**：指出题型和主考点；
2. **入口**：说明由题干哪些特征想到该考点；
3. **推演**：展示规律、要件、关系或论证链；
4. **落项**：逐项排除或说明正确项，给出明确结论。

解析的目标是让学员学会“下一次如何识别”，而不仅是理解“这一次为什么选X”。

### 10.2 用语

优先使用以下稳定表达：

- `元素组成相同/相似/不同，优先考虑……`
- `第一段找规律，第二段验证/应用规律。`
- `第一步：找出定义关键词。`
- `第二步：逐一分析选项。`
- `第一步：判断题干词语间逻辑关系。`
- `论点为……，论据为……`
- `该项与题干讨论话题不一致，属于无关项。`
- `说法过于绝对，无法推出。`
- `直接作用于论点，力度更强。`
- `只有X项符合。`
- `故正确答案为X。`

同一套题的结尾统一使用一种：`故正确答案为X。`或`因此本题选X。`，不交替混用。

### 10.3 解析长度

- 基础题：说明入口、核心规则和答案即可；
- 中档题：补充选项排除；
- 难题：完整展示推导过程，并解释最强干扰项；
- 图形空间题：文字难以复现时必须配标注图，不能用冗长文字硬讲。

解析不得出现“显然”“很明显”代替论证，也不得依赖“看着像”。

## 11. 图文与版式规范

### 11.1 题图

- 黑白题图使用纯净白底、统一黑色线条和一致线宽。
- 题干图、问号和四个选项在同一图片内时，要保持分区明确、间距均衡。
- 选项标号 A—D 位于各选项正下方，字号和基线一致。
- 图像清晰度应满足打印；不得使用模糊截图、拉伸图或带水印图片。
- 同一道题不得把部分选项做成图片、部分选项做成正文。

### 11.2 解析图

- 解析图允许增加编号、箭头、轨迹、辅助线和颜色。
- 红色用于关键变化或当前步骤；蓝色虚线用于参照框、轨迹或辅助结构。
- 标注不得遮挡原始图形，也不得引入未解释的新符号。
- 原题图与解析图分开保存，避免误把带答案标记的图片放入刷题版。

### 11.3 文本格式

- 题号统一为`数字.`，例如`61.`；
- 选项统一为`A.`、`B.`、`C.`、`D.`；
- 中文正文使用全角中文标点；逻辑符号、公式和英文缩写按专业规范书写；
- `？`、`：`、括号和破折号在同一套材料中保持一致；
- 每个选项独立成行，禁止出现`A.……B.……`粘连；
- 复合题必须写清实际子题范围，如`根据材料完成56—58题`。

## 12. 质量控制清单

### 12.1 内容校验

- [ ] 主考点明确，解法可以完整复述；
- [ ] 正确答案唯一；
- [ ] 四个选项均被实际验证；
- [ ] 干扰项对应不同典型错误；
- [ ] 正向题、选非题表述无误；
- [ ] 题干不依赖未提供的冷门常识；
- [ ] 科学材料未把相关关系写成确定因果；
- [ ] 形式推理条件无冲突、无遗漏；
- [ ] 图形规律在所有题干图中成立；
- [ ] 解析与答案一致。

### 12.2 编号与绑定校验

- [ ] 年份、地区和套题编号一致；
- [ ] 题目区与答案区起止题号一致；
- [ ] 复合题说明中的题号范围与实际子题一致；
- [ ] 题号、题图、选项、答案和解析一一绑定；
- [ ] 调换选项后答案字母与解析同步更新；
- [ ] 无缺题、重题、跳号或重复题号；
- [ ] 答案只出现一个有效字母；
- [ ] 无空白答案、`缺失`占位或旧题号残留。

### 12.3 版式校验

- [ ] 四个选项没有粘连；
- [ ] 图片清晰、未裁切、未拉伸；
- [ ] 题图无答案痕迹，解析图标注意义明确；
- [ ] 标点、括号、冒号和题号格式统一；
- [ ] 页首页尾没有孤立题干或孤立选项；
- [ ] 刷题版与教师版内容对应一致。

## 13. 当前样本中不应继承的编辑问题

以下现象属于样本文件的待修订项，不纳入出题风格：

1. 北京卷部分题目区与答案区的年份标题疑似互换：题号为52起的一组与题号为45起的一组，其答案区年份标签需要重新核对。
2. 个别复合题保留了旧题号说明，例如材料写“完成75—77题”，实际子题已调整为56—58题。
3. 2025山东样本中存在直接标注“缺失”的题目和解析，占位内容不得进入正式交付。
4. 2024山东答案区存在空白答案及`CA`双字母答案，应回查原卷确定唯一答案。
5. 部分选项在同一段落中粘连，需拆分为独立选项。
6. `?`与`？`、`--`与`—`、`答案：`与`【答案】`等格式混用，正式成品须按所选模式统一。
7. 个别解析使用“很明显”等跳步表达，应改为可复核的判断依据。

## 14. 后续执行口径

以后根据本规范生成或整理判断推理题时，默认执行以下原则：

- 先确定地区卷风格和成品模式，再开始写题；
- 先完成标准解法和干扰项机制，再写题面；
- 四大题型分别使用各自的识别路径和解析模板；
- 保留真题式自然表达，不把所有题目机械改写成同一句式；
- 解析必须讲清“识别入口—推理过程—选项落点”；
- 图形题优先用干净题图，复杂推理另配标注图；
- 正式交付前完成内容、编号绑定和版式三轮质检；
- 样本中的缺失、错标和格式错误一律不复刻。

本文件是当前工作区内判断推理命题、整编与解析的基准规范。若后续新增更多原创题、课堂讲义或地区卷，可在保持上述骨架不变的前提下补充地区化细则。
