# 判断推理讲题视频通用制作模板

本模板用于持续制作抖音判断推理讲题视频。默认采用题卡、本人配音和逐步推导：学生在上方看原题，在下方看当前步骤，跟随讲解得到答案。每期先完成可审看的成片；发布按用户当次指令执行。

适用图形推理、逻辑判断、定义判断、类比推理和论证题。内容、图示和时长随题目调整，不能把某一期的规律、答案或75.50秒时长直接套给新题。

## 一 下一期直接这样启动

制作记录由制作方填写，用户只需提供题目和特别要求。用户给出题目后，沿用下表的默认项推进。缺少答案时先独立解题；缺少来源时如实记录“用户提供，出处未标”，不编造年份。只有题图不清、题意存在歧义或关键信息确实无法核实时，才询问影响制作的具体问题。

| 项目 | 当前默认 |
| --- | --- |
| 视频形式 | 9:16竖屏，一期讲透一道题或一个方法 |
| 内容结构 | 看题与思考 → 逐步示范 → 应用及选项核对 → 方法归纳；可加同考点练习 |
| 推导布局 | 上方固定完整原题和全部选项，下方独立动态推导，底部保留一句当前重点 |
| 表达风格 | 像当面讲题，具体、有过程；先指出哪里，再解释变化，最后说结论 |
| 音色 | 用户确认的本人音色sangsang，优先保留口音版 |
| 配音速度 | 先沿用已认可的1.0倍生成设置，再依实际试听调整 |
| 视觉 | 深色背景、浅色文字、白色题图区；教学高亮颜色含义一致 |
| 期数显示 | 正片所有页面的右上角不显示“第NNN期”等期数；期号保留在文件名、草稿及知识库记录中 |
| 导出 | MP4、H.264视频、AAC音频、1080×1920、30fps |
| 版本 | 新题独立目录、独立草稿；修改另存版本，保留旧成片 |

执行顺序：复制[单期视频制作记录模板](./短视频索引/单期视频制作记录模板.md) → 审题 → 写分镜和口播 → 制作关键画面 → 生成或复用配音 → 按实际音长排动画 → 合成并导回剪映 → 检查交付 → 更新本期索引和优化记录。

后续可直接使用这句话：

```text
按知识库《判断推理讲题视频通用制作模板》制作第[期数]期。
题目：[题图或题干及选项]
已知答案及解析：[有则提供，没有则先独立核对]
本期特别要求：[没有则沿用默认项]
先完成视频预览、剪映草稿和制作记录。
```

## 二 从题目到成片的流程

| 步骤 | 具体操作 | 完成时留下什么 |
| --- | --- | --- |
| 1 审题 | 保留完整原题，核对题干、选项、答案和推导；明确要讲的一个核心方法 | 原题、答案依据、来源和易错点 |
| 2 分镜 | 将结论拆成可观察的小步骤，明确每句话对应的画面动作 | 分镜表、分段口播稿、配音与画面对应关系 |
| 3 画面预排 | 先做看题、推导、对照答案等关键状态，检查上方原题和下方演示均可看清 | 关键帧预览；图形题保留坐标或其他核对依据 |
| 4 配音 | 审定文本后用已认证音色生成；已有合适音频就复用，只重做发生变化的段落 | 原始配音、使用音色及设置、实测音长、截取位置 |
| 5 排时序 | 以真实音频为准，安排思考静音、叠加、标注、消除、对照和换页 | 各段起止和关键动作时间表 |
| 6 合成 | 渲染最终画面并与配音合成；按本机已验证流程导入独立剪映草稿主轨 | 完整MP4、可修改源、剪映草稿名称及实际路径 |
| 7 验收 | 检查题目、完整播放、声音、关键状态、整片解码和竖屏可读性 | 对应当前版本的检查记录及待处理项 |
| 8 归档 | 提供可播放视频，更新知识库索引；把可复用改进写回本模板 | 本期索引、制作说明、发布文案草稿和反馈记录 |

### 审题要求

原题、演示图、口播、答案必须一致。图形题先独立求出结果，再决定如何演示；不能先认定答案后拼凑动画。线条与区域、旋转与平移、图框与题内元素必须分清。文字题检查条件、否定、范围和推理方向，不能为了缩短口播改掉题意。

原创教学例题明确标原创。采用既有题目时，记录实际可核实的来源；用户提供的题图未标年份，就不称某年真题。完整题目和内容数据放本期素材目录，知识库索引记录入口和检查结果。

## 三 分镜和讲解写法

### 通用四段

四段是内容结构，可以包含多个动画状态，不固定为四张静态图片。复杂题可增加推导步骤；不需要练习时，最后一段直接总结方法。

| 段落 | 学生需要看到什么 | 口播起稿方式 |
| --- | --- | --- |
| 看题与思考 | 完整题目和全部选项，不提前圈答案 | “这道题，你会选哪一个？先看[关键问题]。给你三秒钟。” |
| 逐步示范 | 原题常驻；下方每次只处理一个观察点 | “先看[具体位置或条件]。[发生了什么]。因为[依据]，所以[这一步的结果]。” |
| 应用与核对 | 将规律用到目标图或待判断条件，逐一核对选项 | “把刚才的方法用过来。先[动作]，再[动作]。得到[结果]，与[选项]一致。” |
| 方法归纳 | 提炼可迁移方法，指出本题容易混淆的地方 | “记住[方法]。遇到[特征]，先[第一步]，再[第二步]。注意[边界]。” |

口播要提供观察依据和中间结果，不能只重复“找规律、用规律、选答案”。少用抽象术语串讲；说出具体的线段、尖角、区域、条件或选项差异，让学生知道这一秒该看哪里。

### 不同题型怎样演示

| 题型 | 可以显示的过程 | 必须避免的问题 |
| --- | --- | --- |
| 图形叠加 | 分开观察 → 对齐 → 标出共有或变化部分 → 去掉独有 → 对照选项 | 把透明混色当几何依据，把仅交一点当共同线段；叠加规则随当题变化 |
| 位置或旋转 | 标出参照点和方向，逐步移动或旋转后核对 | 擅自改变原图比例、方向或允许的操作 |
| 数量或属性 | 逐个标记计数对象，显示记录和比较结果 | 漏数、重复计数，把排版外框算入题内 |
| 逻辑判断 | 高亮条件，显示条件关系，再检查结论或反例 | 所有文字题机械画箭头，混淆必要与充分、命题与逆命题 |
| 定义判断 | 拆出要件，按要件核对选项 | 只复述定义，不解释哪项满足或缺少哪个要件 |
| 类比推理 | 说明词语关系，再比较层级、方向和对应方式 | 只说“关系相同”，不说明具体关系 |
| 论证题 | 标出论点、论据和缺口，显示选项如何作用 | 把相关性直接当因果，忽略削弱或加强的具体对象 |

## 四 上方原题下方推导的画面模板

推导全程保持完整原题和全部选项可见。下方演示是对原题的展开，不能覆盖上方条件或把上方题图换成答案图。画面较密时调整分区、减少装饰或分步展示解释，不靠拉伸图形和缩成小字腾空间。

| 区域 | 放置内容 | 检查重点 |
| --- | --- | --- |
| 顶部 | 栏目名和当前步骤标题，右上角不显示期数 | 标题不占用过多原题空间，首段、推导与片尾均无右上角期数 |
| 上方题区 | 完整题干或题图、所有选项 | 推导首尾和场景切换时均完整、位置稳定 |
| 下方演示区 | 当前步骤的图示、标注和变化 | 每次突出一个动作，图形等比例，标注可读 |
| 重点句 | 当前一步的结论或提醒 | 与口播对应，避免堆满解析全文 |

1080×1920画布可先用横向x80—925、纵向不超过1560的关键内容区排版，再按发布预览调整。关键解释和标注通常不小于30px；这是本系列的制作起点，仍需查看真实成片。平台按钮、标题栏遮挡以实际预览为准。

第002讲的可复用排版参考：上方完整题图区x80—900、y290—644；下方将820×770演示板等比缩放到约689×647，放在x146、y700附近。该坐标适合本题宽扁题图，新题按题面比例调整，不能机械裁切或套用。

图形教学默认用蓝色、橙色区分两个来源，绿色表示已核对的保留结果。颜色全片含义一致；绿色是高亮标记，保留什么由题目规则和几何核对决定。原题本身不重染色，不提前高亮正确选项。使用规范化重绘时保留原图及坐标依据，先核对结构、位置关系和结果。

## 五 配音与讲解节奏

### 已确认的选择

沿用用户确认属于本人的sangsang音色，优先选保留口音版。用户反馈标准版抑扬顿挫不足，并明确认为口音版更好；后续已认可第002讲的具体、逐步讲解。已绑定、已认证的音色直接复用，不每期重新上传或认证。

生成前确认当前所选音色、模型、语速及积分。现有会员资格和费用以当时剪映界面为准；遇到新的付费或认证要求再处理，不能把已买会员当作以后功能永久可用的依据。

### 怎样减少一个调调

- 稿件按“提问、观察、动作、结论”自然断句，避免一长段连续说明。关键位置说具体，如“右边这段半圆弧”，让声音跟着画面讲。
- 问句、判断句、提醒句适当交替。结论前留自然短停顿；不要满篇感叹号，或用过大的背景音乐掩盖机械感。
- 先沿用已认可设置。同一句话比较不同模型或速度时尽量只改变一个变量；换音色或大幅改参数，先生成短句试听，再做全片。
- 口播稿与演出说明分开。重读词、停顿秒数和动作提示写进分镜表，不把“此处停顿”“重读”等说明直接交给朗读。
- 轻微变速可以作为对照试听，不能默认0.92倍一定更自然；变速后重排时长。自然度仍不理想时，可采用本人直接录音或本人开头结尾与合成正文衔接，再核对音量和语气。

题目读完后在时间轴实际留约3秒思考静音；倒计时与静音一致。标点不保证暂停长度，不能把句号当三秒暂停。每段结尾保留适当余量，避免截掉尾字。

### 原始导出与额外尾音

本机前两期分段导出曾附带相同固定尾音，不能把各段原始MP3直接拼接当成成片。每次保留完整原始导出，区分主讲结束、静音和额外尾音，再在确认不截正文的位置安排使用段。静音检测帮助找边界，不能代替听辨。

用户已要求去掉末尾额外口播提示。延续该制作要求时保留原始配音及AI生成信息，发布时处理相应平台标识；不把删去口播提示当作去除文件来源信息。一次完整导出也要检查尾部，不假定可以自动避免额外内容。

## 六 剪映操作和减少重复工作的办法

### 本机已验证的制作路线

先在剪映生成本人配音并导出原始音频，在剪映外按真实音长绘制动态画面、合成MP4，再导入新剪映草稿的主轨。第002讲的逐步演示版和原题常驻版均按这条路线完成，正式草稿可播放成片，独立源文件保留用于修改。

1. 制作前在剪映外审定题目、分镜和最终口播，先看关键帧，减少生成后返工。
2. 每期或重要修订新建独立草稿。已验证Ctrl+N可新建并自动保存旧稿；给草稿取清楚的期号、主题或版本名称，确认名称实际保存。记录界面显示的保存位置，不根据草稿名猜文件夹。
3. 在“文本 → 朗读 → 克隆音色”选sangsang，并检查设置中的保留口音版和语速。按实际文本生成需要的段落，原始导出立即使用明确段号保存。
4. 音频导出时核对仅导出需要的音轨、MP3或实际选择的音频格式、文件名和目录。导出窗口可能沿用上期路径，每次检查；导出后核对实际文件，避免把第002期音频留在第001期目录。
5. 按声音安排画面和思考时间，合成完整视频。导入前清理当前制作草稿中的临时测试片段，检查无重复声音或误静音；历史草稿和源文件保留。
6. 已验证Ctrl+I可打开素材导入，再将MP4加入主轨。确认时间轴起点、总长、画布比例、画面和声音。封面可选用本期独立封面图，并核对自动保存状态。

剪映界面布局和控件会变化，操作时依据当前窗口重新观察；不把某次鼠标坐标当通用模板。快捷键也要先确认焦点和选中对象，避免改到标题、文本或错误轨道。

### 哪类修改需要重做什么

| 修改内容 | 处理方式 |
| --- | --- |
| 仅调整原题位置、字号、颜色或上下布局 | 复用已认可配音和时间表，重新生成画面并合成，检查声音沿用正确 |
| 只改一段讲解 | 只重新生成受影响段的配音，再按新音长调整本段和后续起止 |
| 题干、选项、规律或答案改变 | 重新审题、分镜及受影响音频和动画，不能继续用旧检查结论 |
| 改音色、速度或表达设置 | 先短句对照，确认后生成所需段落，重新核对衔接与画面时序 |
| 用户已认可某版，只要求小优化 | 保留认可内容，围绕提出的问题修改，旧成片和原始素材保留 |

可选的剪映内直接排四图、一次生成全文、复制空模板后自动替换等流程，尚未在本系列完成全流程验证。可在副本尝试，但不把它们列为默认已实现能力。已验证的单次完整音频导出仍需检查尾音。

## 七 文件归档与源文件复用

建议每期保留以下结构；已有期次目录保持原有入口，不为套命名而移动历史文件。

```text
短视频/第NNN期_主题/
  原题.png 或 原题.txt
  00_视频封面.png
  配音稿.txt
  原始配音/
  可修改源文件/
  v01_初稿/
  v02_本轮优化/
    第NNN讲_主题_版本.mp4
    关键帧总览.png
    动画时间表.json（使用动画时）
    制作说明.txt
    验证记录.json 或其他实际检查记录

知识库/短视频索引/第NNN讲_主题.md
```

本期索引从[单期制作记录模板](./短视频索引/单期视频制作记录模板.md)复制，记录当前视频、草稿、源、实际检查和用户反馈。所有Markdown记录留在知识库；完整配音稿和素材留本期目录，避免多份题干和答案反复修改后不一致。

第001期build.ps1和第002期render_dynamic.py均包含本期硬编码；只替换JSON不会自动得到新题。复制到独立目录后，逐项改期号、题目、裁切范围、几何、标签、方法、口播、文件名及输出路径，再生成关键帧核对。几何模型随新题重建，不能复用第002题的交集作为新题答案。

本机制作依赖曾使用Pillow与FFmpeg；录入实际使用路径和运行方式，环境改变时先检查。文件复用要明确依赖：第002讲原题常驻版仍读取上一层原题和总结题卡，单独复制脚本并不等于完整素材包。后续归档应列出依赖并保持链接可用。

## 八 交付前验收和反馈闭环

- [ ] 题干、选项、答案、演示和口播一致，来源记录真实，题目已独立复核。
- [ ] 推导全程上方完整原题和全部选项可见、无遮挡；下方当前步骤可直接对照，图形比例正确。
- [ ] 每个关键动作有具体讲解；结论由过程得到，未提前泄露作答阶段答案。
- [ ] 图形对齐、移动、交集或计数已核对，结果与选项同方向、可比较；抽查看题、移动、高亮、消除、对照及两段切换。
- [ ] 首段、各推导段和片尾的右上角均不显示期数；段落进度、文件名和知识库期号不受影响。
- [ ] 关键字和标注在实际成片中可读，没有裁切、堆叠、过小文字；封面和字幕与内容一致。
