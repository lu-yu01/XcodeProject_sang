# 近五年文字判断推理研究与110题蓝图

本轮按用户要求新增110题文字专项，以2022—2026年国考为主，2026、2025题面优先，地方考试辅助。出题参考的是关系层级、信息组织、设问方向和干扰机制，不直接改写真题表述。2021年属于可补充范围，本轮具体文字样本未用2021题，不能写成已经覆盖六年全卷。

以上为分模块107条研究记录，不是107份卷，也不是各年题型频率的统计样本。本地资料包含网友回忆、培训整理及合订材料，未声称获得官方完整题库或官方逐题答案。资料正文及来源年款优先于文件名，已有以下纠偏：

- 2025副省题本的类比是101—105题，96—100题仍属定义；按编号机械提取会错归模块。
- 2025三类中多个类比及论证题相同，跨卷出现不作为多份新考点计权。
- 标为2025的地方定义题整理文件中有正文2024、2023及2022题，记录采用具体题目的年份。
- 一份2022执法合订本的第105题正文标为2022辽宁；论证研究将其作为地方题，未冒充国考。
- 部分2025分卷文件没有内嵌年份页，仅由目录与同套课件年章交叉核对；这一证据边界保留在具体来源记录中。

这些是所读题例体现的机制，不据此宣称某机制逐年增加或占官方试卷多少。详细原题定位和适用限制以四份来源记录为准。

## 本轮原创配额

| 题号 | 配额与结构 |
| --- | --- |
| 1—20 | 类比20：语义、语法、借称、加工、关系角色、集合、公式、填空等；19—20使用概念关系图 |
| 21—50 | 定义30：相邻/多定义、主体与对象、程序、因果机制、抽样、测量、指标、生态等；选非与正问混排 |
| 51—55 | 一拖五第一组：监测站启用，布尔条件、异或、配置数量；基准10解 |
| 56—60 | 一拖五第二组：人员/文件多对多分配，容量、禁配、等价条件；基准56解 |
| 61—65 | 一拖五第三组：不同时长任务与共享资源排程，允许指定并行；基准17解 |
| 66—80 | 独立15：翻译4、真假4、分析4、平行结构3 |
| 81—110 | 论证30：加强10、削弱10、必要前提4、解释3、评价2、归纳1 |

所有题目为单选。三组共用材料中，每题增加的条件仅对本题生效。110是用户指定训练配额，不代表国考判断推理整卷题量；允许分模块练习，不虚拟官方用时。

## 知识与语义核验

类比涉及的事实只保留到常见关系识别所需的层级：泪液的分泌与成分参照[美国国家眼科研究所](https://www.nei.nih.gov/eye-health-information/healthy-vision/how-eyes-work/how-tears-work)，汗液参照[克利夫兰诊所](https://my.clevelandclinic.org/health/body/sweat)，鲸类参照[NOAA渔业](https://www.fisheries.noaa.gov/whales)及[NOAA海洋科普](https://oceanservice.noaa.gov/facts/dolphin.html)。借称及成语用法的词典、教育部门与文化资料链接见类比来源报告。它们用于排除命题事实错误，不构成对考生的额外专业知识要求。

定义题由题干提供操作判准，专业来源用于校对定义合理性。自主限定须明示适用本题，不能给既有概念杜撰互斥关系。论证中的机构、数字和研究场景为练习设定，不以真实研究背书。

## 验收边界与修订

- 形式逻辑使用完整声明范围内的枚举、真值、小模型界或结构同构验证，逐项有见证/反例。
- 类比关系标签与定义要件矩阵属于编辑辅助；程序不会理解全部自然语言。论证的数值及否定例检查同样不等于自动证明最强项。
- 未见答案的代理交叉试解保留首次结果；修改后再作修订复核。首轮认为有歧义、偏易或不自足的题不删去审稿痕迹。
- 已据复核修正类比的命名来源层级与目的/工具/方法区分；定义双盲补参与者未知分组；价格论证补成本基数和加成比例口径；后续明示与最终状态见本卷索引。
- 难度为作者及复核者的命题估计，保留梯度；未开展独立教师盲审、学员试测或通过率标定，不宣称与某年原卷实测难度完全相同。
